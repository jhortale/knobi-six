# MIDI CC (docs/MIDI.md): one CC per continuous parameter; FILTER FREQ = CC 74, RESONANCE = CC 71. A CC received sets
# the param (PARAM RX on, the default) and is not sent back; an edit on the panel goes out as its CC (PARAM TX on, the
# default) on the MIDI channel (ALL = 1). "ccout N": the last value sent on CC N (-1: none). Globals (GLOBE): K2 MIDI
# CH (0 = ALL, 1..16) = glob 0, K4 PARAM TX = glob 2, K5 PARAM RX = glob 3. Also the mod wheel (CC 1), sustain (CC 64,
# the HOLD), pitch bend and program change + bank select (CC 32; programs are Task 10's: a stub records the request),
# CC 7 volume ("vol"), CC 123 all notes off (released, the HOLD pad's latch "holdpad" unchanged), CC 120 (PANIC).
