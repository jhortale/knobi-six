# KNOBI Monorepo (step 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the repo into a pnpm + Turborepo monorepo beside upstream's untouched layout: `web/` becomes
`apps/installer` built from shared `@knobi/*` packages, KNOBI-SIX's metadata moves to `synths/knobi-six/`, same
behaviour and tests.

**Architecture:** Upstream's paths (`firmware/`, `tools/`, `tests/`, `build.sh`) do not move. A pnpm workspace
(`apps/*`, `packages/*`, `synths/*`) grows beside them; packages are consumed as TypeScript source (no prebuild).
The split is done one package at a time, with the whole suite green after each task (`web/` stays the app until
Task 7 renames it).

**Tech Stack:** pnpm 12.21.0, Turborepo 2.11.13, Node 24, Vite 8.3.8, Vitest 5.1.1, React 19.3.1, TypeScript 7.0.2,
Tailwind 4.3.5, shadcn/ui.

**Spec:** `docs/superpowers/specs/2026-11-20-monorepo-design.md` (approved; binding).

## Global Constraints

- Never touch: `firmware/**`, `tools/**` (read-only for tests), `tests/**` except `tests/web_fixtures.py`'s documented
  output path, `build.sh`, `LICENSE`, `LICENSES/`. `build.yml` unchanged.
- No keyboard is ever used; the installer is exercised only through `@knobi/device-sim` (CLAUDE.md).
- Packages: `"private": true`, scope `@knobi/`, `exports` pointing at `src/*.ts(x)`; exact version pins; one root
  `pnpm-lock.yaml` (no `package-lock.json` anywhere).
- No dependency cycle: `installer-core` never depends on `device-sim`, not even as a devDependency.
- `@knobi/device-sim` is only ever a devDependency, and never reaches `apps/installer/dist/`.
- Every move is `git mv` (history follows); GPL-3.0-only headers and credits on ported files kept; shadcn files MIT.
- The suite keeps every test that exists on `phase1` (135 passing + 1 skipped by `build/knobi-six.fwsc` absence); a
  test may move but not disappear. Expected totals after each task are given; any drop is a failure.
- `LICENSING.md`: never drop a row; do **not** rewrite the PolyBLEP row's `web/synth/analog.c` (smk37-analog's path).
- Commits: conventional, end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The lockfile on Linux** (CI): `pnpm install --frozen-lockfile` must work on Linux x86-64 as well as macOS
   (platform-specific optional deps). Pinned by Task 8's container run.
2. **Tailwind not seeing `packages/ui`'s classes**: Tailwind v4 scans only the app by default, so shadcn's classes
   would silently vanish from the built CSS. Pinned by a `dist.test.ts` assertion in Task 6.
3. **A malformed or missing `synths/<id>/synth.json` / `catalog.json`**: the generator must stop with an error naming
   the file, not throw a TypeError or publish a partial catalog. Pinned in Task 5.
4. **The generator under plain `node` through workspace symlinks** (`node_modules/@knobi/*` → `packages/*`): Node's
   type stripping refuses files inside `node_modules`, so imports must resolve to real paths. Pinned by the CLI test in
   Task 5.
5. **An upstream merge after the restructure**: `git merge-tree` against `upstream/main` must show no conflicts
   caused by this work. Pinned in Task 8.
